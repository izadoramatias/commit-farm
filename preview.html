COMMIT FARM / MVP 01

Um dia. Um canteiro.

Seu calendário de contribuições virou uma fazendinha. Cada broto, folha e cenoura representa um dia de código crescendo.

Passe o mouse sobre um canteiro para ver a data e a quantidade de contribuições. No celular, deslize o cenário para os lados.

O arquivo inicial usa dados fictícios, identificados no desenho. Após a primeira execução no GitHub, esta mesma página exibe seus dados reais.
Abra README.md para configurar. Arte original em SVG; sem bibliotecas ou imagens externas.
